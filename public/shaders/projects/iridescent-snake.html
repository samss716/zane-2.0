Iridescent Snake Shader

A Shadertoy 2.5D shader using a normal map, diffuse and specular lighting, thin-film-inspired color, and Voronoi-based variation.

GLSL · Shadertoy


#define PI 3.14159265

// Convert HSV color to RGB.
// Hue controls the color, saturation controls its intensity,
// and value controls its brightness.
vec3 HSVtoRGB(vec3 c)
{
    vec3 rgb = clamp(
        abs(mod(c.x * 6.0 + vec3(0.0, 4.0, 2.0), 6.0) - 3.0)
        - 1.0,
        0.0,
        1.0
    );

    rgb = rgb * rgb * (3.0 - 2.0 * rgb);

    return c.z * mix(vec3(1.0), rgb, c.y);
}

// Voronoi pattern used to vary the iridescence.
float voronoi(vec2 uv)
{
    vec2 cell = floor(uv);
    vec2 localUV = fract(uv);

    float minDist = 1.0;

    for (int y = -1; y <= 1; y++)
    {
        for (int x = -1; x <= 1; x++)
        {
            vec2 neighbor = vec2(float(x), float(y));
            vec2 point = neighbor;

            float seed = sin(
                dot(cell + neighbor, vec2(127.1, 311.7))
            ) * 43758.5453;

            point += vec2(
                fract(seed),
                fract(seed * 1.2154)
            );

            float dist = length(localUV - point);

            minDist = min(minDist, dist);
        }
    }

    return minDist;
}

void mainImage(out vec4 fragColor, in vec2 fragCoord)
{
    vec2 uv = fragCoord / iResolution.xy;

    // Texture maps
    vec3 normalSample = texture(iChannel0, uv).rgb;
    vec3 albedo = texture(iChannel1, uv).rgb;
    float Ks = texture(iChannel2, uv).r;
    float AO = texture(iChannel3, uv).r;

    // Surface normal from the normal map
    vec3 N = normalize(normalSample * 2.0 - 1.0);

    // Fixed view direction
    vec3 V = vec3(0.0, 0.0, 1.0);

    // Fixed light direction for diffuse illumination
    vec3 L = normalize(vec3(-0.4, 0.6, 1.0));

    float ndotl = max(dot(N, L), 0.0);
    float ndotv = max(dot(N, V), 0.0);

    // Basic ambient and diffuse lighting
    float Kd = 0.9;
    float Ka = 0.15;

    vec3 ambient = albedo * Ka * AO;
    vec3 diffuse = albedo * Kd * ndotl;

    // Identify the snake based on the albedo brightness to keep background dark
    float brightness = dot(
        albedo,
        vec3(0.299, 0.587, 0.114)
    );

    float snakeMask = smoothstep(0.025, 0.16, brightness);

    // Angle-based iridescence, following the class-style approach.
    // The hue changes as the surface normal turns away from the viewer.
    float angle = 1.0 - ndotv;

    // Voronoi variation changes the hue across the surface.
    vec2 scaleUV = uv * vec2(24.0, 36.0);
    float cellDist = voronoi(scaleUV);

    float scaleVariation = smoothstep(0.05, 0.65, cellDist);

    float hue = fract(0.55 + angle * 0.35 + scaleVariation * 0.06); //color control

    vec3 iriColor = HSVtoRGB(
        vec3(hue, 0.8, 1.0)
    );

    // Blend iridescence with the original snake color
    float iriStrength = 0.60;

    vec3 baseColor = mix(
        albedo,
        iriColor,
        iriStrength * snakeMask
    );

    // Apply diffuse lighting to the iridescent base color
    diffuse = baseColor * Kd * ndotl;

    // Mouse-controlled specular highlight
    vec2 mousePixel = iMouse.xy;

    // Using the screen center when the mouse has not been positioned
    if (mousePixel.x == 0.0 && mousePixel.y == 0.0)
    {
        mousePixel = 0.5 * iResolution.xy;
    }

    float lightHeight = 250.0;

    vec3 lightPosition = vec3(mousePixel, lightHeight);
    vec3 surfacePosition = vec3(fragCoord, 0.0);

    vec3 Lspec = normalize(lightPosition - surfacePosition);
    vec3 H = normalize(Lspec + V);

    float ndoth = max(dot(N, H), 0.0);
    float shininess = 20.0;

    float specularStrength = pow(ndoth, shininess) * Ks;

    vec3 specular = vec3(1.0) * specularStrength * 0.8;

    // Combine lighting
    vec3 finalColor = ambient + diffuse + specular;

    finalColor = max(finalColor, vec3(0.0));

    // Gamma correction
    finalColor = pow(finalColor, vec3(1.0 / 2.2));

    fragColor = vec4(finalColor, 1.0);
}

Section 3

Development steps and examples

  1. Display and assign the maps. The normal map supplies per-pixel surface orientation, the albedo supplies the snake's color, the specular map controls highlight strength, and the AO map darkens the ambient contribution. The final shader samples these maps rather than only displaying them.
  2. Add diffuse lighting. The shader calculates max(dot(N, L), 0.0). This Lambert-style term brightens surfaces facing the fixed light and darkens surfaces facing away.
  3. Add specular highlights. Blinn–Phong shading uses H = normalize(Lspec + V). The specular map scales the highlight, and iMouse moves the point light. Diffuse lighting stays fixed.
  4. Add iridescence. I implemented iridescence using HSV color conversion. The shader calculates the angle between the surface normal and the fixed view direction, then uses this value to influence the hue.
  5. Add Voronoi variation. I added a Voronoi pattern to introduce variation across the snake's scales. The shader calculates the distance to nearby procedural points and uses that value to adjust the hue. This adds localized color variation while preserving the underlying texture and surface detail.
  6. Blend the iridescence with the original color. The shader blends the iridescent color with the original albedo using a mask based on texture brightness used to identify the snake. This ensures that the background remains dark while the snake exhibits vibrant iridescence.

Channel Map Purpose
