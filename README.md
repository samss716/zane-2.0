# Zane 2.0 | Creative Portfolio

A personal portfolio exploring the intersection of **new media art, creative development, and technical art**. Built to showcase digital experiments, 3D work, interactive experiences, and the processes behind them.

**Live Site:** [zane-2-0.vercel.app](https://zane-2-0.vercel.app)

## Overview

Zane 2.0 is a continuously evolving portfolio repo and digital archive documenting my work across visual computing, 3D graphics, simulation, and creative coding.

The site features an editorial-inspired interface with interactive elements and custom visual components. It serves as both a presentation space for finished projects and an evolving record of experimentation across different creative technologies.

## Features

- **Interactive 3D:** Embedded GLB model viewer powered by Three.js and React Three Fiber.
- **Motion & Animation:** Custom scroll-triggered reveals, animated typography, and looping marquee elements.
- **Creative Showcases:** Organized project collections featuring 3D modeling, digital art, simulations, and video work.
- **Responsive Design:** Adaptive layouts and interactions for desktop and mobile.
- **Visual Effects:** Custom shaders, gradients, and ambient visual treatments.
